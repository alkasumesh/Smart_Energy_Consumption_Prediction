Week 8 – Web Application Deployment
Flask API Routes

GET / → Loads main dashboard
POST /api/predict → Returns predicted kWh and bill
GET /api/refresh-charts → Regenerates all charts

User Inputs (Prediction Form)

Number of household members
Appliances used at home
Target month
Electricity rate (₹ per unit)

Hidden ML Features (auto-generated by backend)

lag_1, lag_24, rolling_mean_24, Home ID, Outdoor Temperature
Never exposed to the user

Prediction Method
Physics-based estimate blended with trained Linear Regression model.
Final kWh = 55% physics estimate + 45% ML model output.
Web Interface Pages

Home – Introduction and navigation
Charts – All 5 visualisation charts
Predict – 3-step wizard for bill prediction
Tips – 8 energy-saving tips with savings estimates

Deployment
App runs locally using Flask development server.
URL: http://127.0.0.1:5000
Command: python app.py
